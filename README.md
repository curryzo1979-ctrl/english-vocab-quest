# 英語クエスト

小6向けのスマホ用英語Webアプリです。英単語154問に加え、学校プリントA〜Eをもとにした文法問題52問を収録しています。

- 4択クイズ / スペル入力
- 動詞は現在形・過去形を別々に入力
- 現在形→過去形、過去形→現在形の直接入力モード
- 空所補充・会話の選択問題
- 単語カードを使った英文並べ替え
- 並べ替えと同じ問題を語群なしで解く英作文入力
- 単元別出題
- 苦手単語だけ復習
- 100問をミスだけ繰り返して全問正解する完全攻略モード
- 正答率・連続学習日数を端末内に保存
- ホーム画面追加・オフライン利用対応（PWA）

個人情報や学習記録はサーバーへ送信しません。
